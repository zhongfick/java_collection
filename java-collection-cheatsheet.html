4. Stream

链式处理集合和数组数据
操作写法说明
创建集合流stream()从集合创建 Stream
创建并行流parallelStream()创建并行 Stream，刷题中通常不需要
数组转流Arrays.stream(array)适用于基本类型数组和对象数组
筛选filter(predicate)保留满足条件的元素
转换map(function)将每个元素转换成另一种结果
扁平转换flatMap(function)将多个流合并成一个流
去重distinct()去除重复元素
排序sorted()自然升序排序
自定义排序sorted(comparator)按比较器排序
跳过skip(n)跳过前 n 个元素
限制数量limit(n)只保留前 n 个元素
遍历forEach(action)对每个元素执行操作
转 Listcollect(Collectors.toList())收集为 List
转 Setcollect(Collectors.toSet())收集为 Set 并去重
转数组toArray()转为 Object[]
计数count()返回元素数量
求和mapToInt(x -> x).sum()整型流求和
最大值max(comparator)返回 Optional
最小值min(comparator)返回 Optional
全部满足allMatch(predicate)所有元素满足条件
任意满足anyMatch(predicate)至少一个元素满足条件
没有满足noneMatch(predicate)没有元素满足条件
查找任意元素findAny()返回 Optional
查找第一个findFirst()返回 Optional

筛选、转换、收集

    .filter(x -> x % 2 == 0)
    .map(x -> x * 2)
    .collect(Collectors.toList());

    .collect(Collectors.toList());

8. Map

键值对、统计、映射
操作写法说明
添加 / 覆盖put(key, value)key 已存在时覆盖 value
获取get(key)key 不存在时返回 null
默认获取getOrDefault(key, defaultValue)不存在时返回默认值
判断 keycontainsKey(key)判断是否包含 key
删除remove(key)删除指定键值对
获取所有 valuevalues()返回所有 value 的集合视图
value 转 Listnew ArrayList<>(values())将所有 value 转为可修改的 List

常见实现： HashMap 无序、平均 O(1)；LinkedHashMap 保持插入顺序；TreeMap 按 key 排序、O(log n)。

Map<String, Integer> map = new HashMap<>();
map.put("a", 1);
map.get("a");
map.getOrDefault("b", 0);
map.containsKey("a");
map.remove("a");
List<Integer> values = new ArrayList<>(map.values());

for (Map.Entry<String, Integer> entry : map.entrySet()) {
    String key = entry.getKey();
    int value = entry.getValue();
}

for (int x : nums) {
    count.put(x, count.getOrDefault(x, 0) + 1);
}

分组

groups.computeIfAbsent(
    key, k -> new ArrayList<>()
).add(value);

Map value 转 List

return new ArrayList<>(map.values());

9. PriorityQueue

优先队列 / 堆
操作写法复杂度
入堆offer(x)O(log n)
查看堆顶peek()O(1)
删除堆顶poll()O(log n)
判空isEmpty()O(1)
 
// 小根堆：默认
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

// 大根堆
PriorityQueue<Integer> maxHeap =
    new PriorityQueue<>(Collections.reverseOrder());

minHeap.offer(3);
minHeap.peek(); // 查看最小值
minHeap.poll(); // 删除最小值
