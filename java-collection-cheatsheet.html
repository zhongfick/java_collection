1. List

有序、可重复、支持下标
操作写法
添加add(x)
指定位置添加add(i, x)
获取 / 修改get(i) / set(i, x)
删除remove(i)（下标）或 remove(Integer.valueOf(x))（对象）
查询size()、isEmpty()、contains(x)、indexOf(x)
排序 / 反转sort(Integer::compareTo)、Collections.reverse(list)
 
List<Integer> list = new ArrayList<>(Arrays.asList(3, 1, 2));
list.add(4);
list.remove(Integer.valueOf(1));
list.sort((a, b) -> b - a); // 降序

2. Deque

双端队列，包含队列功能
操作头部写法尾部写法
添加addFirst(x)addLast(x)
删除removeFirst()removeLast()
查看peekFirst()peekLast()
刷题别名push(x) / pop()offer(x) / poll()
 
Deque<Integer> deque = new ArrayDeque<>();
deque.addFirst(1);     // 头部添加
deque.addLast(2);      // 尾部添加
deque.removeFirst();   // 头部删除
deque.removeLast();    // 尾部删除
deque.peekFirst();
deque.peekLast();

3. Set

元素去重，基础操作
操作写法说明
添加add(x)重复元素不会重复添加
删除remove(x)删除指定元素
判断包含contains(x)判断集合中是否存在元素
元素个数size()返回集合大小
判空isEmpty()判断集合是否为空

常见实现： HashSet 无序、平均 O(1)；LinkedHashSet 保持插入顺序；TreeSet 自动排序、O(log n)。

Set<Integer> set = new HashSet<>();
set.add(1);
set.contains(1);
set.remove(1);

4. TreeSet

自动排序，包含 Set 基础操作
操作写法说明
添加add(x)添加元素并自动维护顺序
删除remove(x)删除指定元素
判断包含contains(x)判断集合中是否存在元素
元素个数size()返回集合大小
判空isEmpty()判断集合是否为空
最小 / 最大值first() / last()获取最小或最大元素
小于 / 小于等于lower(x) / floor(x)获取 x 左侧的最近元素
大于 / 大于等于higher(x) / ceiling(x)获取 x 右侧的最近元素
 
TreeSet<Integer> treeSet = new TreeSet<>();
treeSet.add(3);
treeSet.add(1);
treeSet.add(2);
treeSet.first();   // 1
treeSet.last();    // 3

5. Map

键值对、统计、映射
操作写法说明
添加 / 覆盖put(key, value)key 已存在时覆盖 value
获取get(key)key 不存在时返回 null
默认获取getOrDefault(key, defaultValue)不存在时返回默认值
判断 keycontainsKey(key)判断是否包含 key
删除remove(key)删除指定键值对

常见实现： HashMap 无序、平均 O(1)；LinkedHashMap 保持插入顺序；TreeMap 按 key 排序、O(log n)。

Map<String, Integer> map = new HashMap<>();
map.put("a", 1);
map.get("a");
map.getOrDefault("b", 0);
map.containsKey("a");
map.remove("a");

for (Map.Entry<String, Integer> entry : map.entrySet()) {
    String key = entry.getKey();
    int value = entry.getValue();
}

频率统计

for (int x : nums) {
    count.put(x, count.getOrDefault(x, 0) + 1);
}

分组

groups.computeIfAbsent(
    key, k -> new ArrayList<>()
).add(value);

6. PriorityQueue

优先队列 / 堆
操作写法复杂度
入堆offer(x)O(log n)
查看堆顶peek()O(1)
删除堆顶poll()O(log n)
判空isEmpty()O(1)
 
// 小根堆：默认
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

// 大根堆
PriorityQueue<Integer> maxHeap =
    new PriorityQueue<>(Collections.reverseOrder());

minHeap.offer(3);
minHeap.peek(); // 查看最小值
minHeap.poll(); // 删除最小值
